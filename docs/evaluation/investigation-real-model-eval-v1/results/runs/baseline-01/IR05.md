### 为什么"传播结论"统计不出来

传播分析（propagation）本质是对**已持久化帖子/评论/转发边**做时间、平台、账号、内容维度的计量——例如：
- 时间线：按天计数、峰值日、爆发窗口
- 平台分布：各平台占比
- 主体集中度：单一账号/媒体占比、转发路径
- 互动结构：评论、转发、引用的边关系

这些指标全部分母为 0，因此：
- 可以给出的只有"空集"这一事实（0 条、无 bucket、无时间跨度）；
- **不能**给出任何峰值、趋势、占比、来源集中度、协调模式等结论。

若强行生成，就是无源推断（fabrication），违反"所有事实性结论必须引用工具返回的 Post / Comment / Evidence / Artifact ID"的约束。

### 数据库现在能支持什么（在 0 数据前提下）

仍然**能**支持的是"事实性空值陈述"和"结构/流程查询"，而不是传播内容分析：

1. **精确计数与分布**：`get_case_data_overview`、`aggregate_social_data`（platform / day / content_type）——当前一律为 0。
2. **精确记录查询**：`query_social_posts`、`query_social_comments`、`get_social_post`——当前返回空列表，可确认"某条不存在"。
3. **流程与产出状态**：`query_findings`、`query_review_items`、`query_reports`、`query_case_activity`——当前均为 0/无记录。
4. **语义检索**：`search_social_evidence`——无可检索内容。
5. **调查完整度诊断**：`get_investigation_quality`——可查询，但在 0 数据下必然给出"数据覆盖不足、不具备报告准备度"的判断。

**不能**支持的：任何传播规模、热度、趋势、平台对比、账号协调性等**需要帖子作为分母**的结论。
