### 数据库能支持什么（有数据后）

**1. 精确计数与分布（确定性，非估算）**
- 总量与按平台分组（`aggregate_social_data` group_by=platform）
- 按天分布 → 传播时间线与峰谷（group_by=day）
- 按内容类型分布（group_by=content_type）
- 支持日期区间、平台、关键词（子串）过滤后再聚合

**2. 精确记录清单**
- 帖子列表/最新帖子：平台、作者、日期范围、排序、分页（`query_social_posts`）
- 单条帖子精确抓取（`get_social_post`，可按 post_id 或 platform+native_id）
- 评论清单与某帖下评论（`query_social_comments`）

**3. 语义证据发现**
- `search_social_evidence`：按语义相关性找证据、产出稳定 Evidence ID（注意：它是发现工具，**不是**精确计数/完整列表的权威来源）

**4. 结论与工作流状态**
- Findings 及其状态（candidate / under_review / verified / rejected）——只有 verified 才是人工复核接受的结论
- Review Items 与人工复核决定
- Reports 及发布状态

**5. 调查完备度**
- `get_investigation_quality`：采集覆盖、证据覆盖、Finding 支撑、复核收敛、溯源完整性、报告引用等维度评分（衡量**完备度/准备度，不是事实真伪**）

**6. 关联与信号（跨 Case / 主体 / 异常）**
- `query_related_investigations`：共享主体/帖子/媒体/内容的历史关联（candidate 关联仅是指示线索，非已核实）
- `query_workspace_entities` / `get_workspace_entity`：主体在哪些事件出现、有哪些平台身份
- `query_signals`：协调行为、重复主体/媒体、高重叠 Case 等异常信号（风险信号 ≠ 恶意行为证明）
